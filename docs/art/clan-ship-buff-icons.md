# Clan ship buff icons

Current UI assets: public/clan-ship-buffs/user-v1/*.webp, extracted from the user-supplied sheet preserved as user-v1/source.png. Fourteen individual transparent images follow SHIP_BUFFS order; padded thumbnails use object-fit contain. These replace the generated atlas in the UI.

Generated with the built-in image_gen tool. Production asset: public/clan-ship-buffs/atlas-v3.webp. The preferred user reference is preserved in docs/art/clan-ship-style-reference.png. Future icons should follow its worn mechanical shapes, acidic glow and comedic adult sci-fi cartoon direction (Rick and Morty / Futurama), while reusing consistent object designs across the family.

One transparent 4-by-4 atlas, fourteen icons in SHIP_BUFFS order; the final two cells are empty. ShipBuffIcon renders the shared atlas without cropping source files.

Art direction: thick dark brown hand-drawn outlines, restrained wear, two-tone cel shading, ochre yellow, peach, olive, lime, rusty orange, red and silver. Reuse one finger, yellow pencil with pink eraser, green poison bottle, stopwatch and clockwise cooldown arrow across the family. No labels, backgrounds or frames.

Subjects in reading order: finger cooldown reset; pencil cooldown reset; finger damage; pencil damage; all poison damage; poison preservation; bleed duration; bleed damage; pencil cooldown reduction; finger cooldown reduction; critical damage; raid damage; opening hit; daily poison supply.
