# BETA 2.66

Player diagnostics from server 2.65 confirm successful attack requests up to 4196 ms, clan quests up to 4536 ms, chat up to 4592 ms and event data up to 3040 ms. These observations do not identify hosting/network latency by themselves.

Changes:

- Boss expiration indexes owners once and skips completed fights instead of searching all players for every historical fight. Regression test: 5000 historical fights and 1000 players require roughly 1000 player-key reads instead of millions.
- Routine global persistence is debounced for production too. Explicit payment and wallet persistence remains unchanged.
- Clan quests prefetch when the member profile opens, share a query cache, preserve cached data during refresh and display loading/error status instead of an unexplained empty panel. Quest actions reject duplicate in-flight calls.
- Halloween adopts prefetched data received after mounting. Previously this payload could cancel the initial fetch without updating the screen until the next 15-second poll. Camp prepares the data in advance; opening still refreshes it.
- Reward confirmation blocks immediately before React rerenders. Roulette keeps the claim popup visible until confirmation finishes; its pending-reward message sits on the claim button rather than over the wheel.
- Fishing start and resolve reject concurrent requests and handle failures without unhandled promise rejections.
- Removed decorative clan reward badges above the stats. The four functional clan progression achievements remain.
- Hidden Pumpkin Talisman from the unowned equipment catalog and event shop. Existing owned items and their bonuses remain intact.

Validation: targeted latency/navigation/battle/claim tests passed, changed-file lint passed, production build passed. Full suite before the final fishing error-handler adjustment: 258/269 passed; 11 remaining failures in the existing Halloween/date, equipment-count and referral tests.
