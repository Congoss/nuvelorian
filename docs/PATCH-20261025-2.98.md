# Web account sign-in

Web entry offers Telegram login and NEAR wallet signature login. NEAR login only restores a unique existing player with a verified linked wallet; it never creates or merges accounts. The server validates a browser-bound, expiring, single-use NEP-413 challenge and the account's FullAccess key through RPC. Unlinking the wallet revokes NEAR-authenticated sessions.

Deployment prerequisite: in @BotFather select the game bot (default planet_4bot), register https://p4.nuvelor.gg under Login Widget / Allowed URLs, or use /setdomain with p4.nuvelor.gg for the legacy widget. This resolves the Telegram-side Bot domain invalid error. See https://core.telegram.org/widgets/login/ . Until configured, Telegram profile -> Web game remains the launch-token fallback.
