# Беззаконня. Список і перевірка готовності

## Порядок ручної перевірки

- [ ] 1. Відкриття вкладки, ціни, підказки вимог. «З розгону» заблоковано без трьох передумов на 5/10. Другий сектор закрито на 9/10 і відкрито на 10/10.
- [ ] 2. Два пальці й Клізма. Заміна і повернення базових ударів, шкода, спільний час відновлення, кровотеча.
- [ ] 3. Шкрябан. Перше попередження, підказки щитів, фіолетова хмара й написи блоку та пробою.
- [ ] 4. Отрута ×1/×5/×10/×100. Блок усієї партії, пробій на 10–20 с, повернення доз.
- [ ] 5. Мітки, підрив, кровотеча та крит. Перевірити кожен талант другого сектора.
- [ ] 6. Повна прокачка, скидання та збереження стану після перезавантаження.

Локальне прев’ю використовує тестовий профіль. Збереження після перезавантаження слід перевіряти через серверний профіль.
